# 🍷 reverse-engineering a wine blend

this repo hosts the raw data and Python code to completely reproduce the results and figures of our article:
> C. Simon, T. Onufer, A. G. Andrade, E. Tomasino. "Estimating the make-up of a blend in terms of its parent mixtures based on chemical fingerprints: e.g. reverse-engineering a wine blend." (2025)

_instructions_: run `wine_blending.py` as the marimo notebook.
